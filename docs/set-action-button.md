# Set action button

Picks the controller button used by the `action button pressed` and `action button just pressed` predicates for this sprite. Any controller button can be the action button: A, B, or a direction. Player 1's buttons are used unless a different controller is configured with the "control facing direction with buttons" block.

## Parameters

- **sprite**: the sprite to set the action button for
- **button**: the button that acts as the sprite's action button
